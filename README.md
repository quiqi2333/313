# 313

一份个人项目协作 Skill，用于设计、研究及多轮成果修改。

## 工作方式

- **模型分工与自主委派**：默认由 Luna 6 极高负责读取、检索和执行，Astra 6 中负责分析、规划并指导复杂制作。主代理自行拆分和分派任务，独立任务可并行，最后负责整合与检查。简单任务直接完成。
- **先理解相关材料**：结合本次任务书、老师要求和已有成果形成判断。
- **按当前阶段推进**：尊重先分析、先比较、先文字或直接制作等当次要求。
- **保留已确认内容**：聚焦指定修改，保留明确要求沿用的文字、数据、底图、构图、结构与范围。
- **选方案时比较**：需要选型时，比较可行方案、优缺点及相关实际案例。
- **核对视觉参考**：按本次指定的颜色、比例、排版、材质等细节落实参考与修改。

当次指令优先于默认分工。所需模型和子代理能力须在运行环境中实际可用；本 Skill 不会安装模型或修改全局模型配置。

## 文件

- [SKILL.md](SKILL.md)：完整协作规则。
- [agents/openai.yaml](agents/openai.yaml)：展示名称和简介。

## 使用

将本仓库内容放入个人技能目录下的 `313` 文件夹，保持以下结构：

```text
313/
├── SKILL.md
└── agents/
    └── openai.yaml
```

在支持该 Skill 的 Codex 环境中调用：

```text
$313
```

也可把仓库链接交给支持 GitHub 安装的技能安装器处理。

此仓库仅包含最终技能规则与使用说明，不包含用于整理习惯的私人聊天记录。
